# Brand logos

Drop one image per brand here, named by the brand's slug: lowercase, spaces and symbols become `-`.
Examples: `ford.png`, `mercedes-benz.png`, `land-rover.png`, `new-flyer.png`, `bmw.png`.

- PNG with a transparent background, square, about 256 × 256 px.
- Use logos you have the right to use (e.g. from the manufacturer's media / press site, or with written permission).
- Then run `npm run brand-logos` from the project root. It regenerates `src/data/brand-logos.ts`.

Brands without a file show their initials instead.
